# Hakan Berat Demircan

I build web and mobile applications with C# and .NET. I spent ten years running a scuba diving center in Famagusta, and that experience shapes the software I build today. My projects tackle tasks I know firsthand, from handling reservation requests to organizing dive center operations.

## Selected projects

- [Scuba Diving Marketplace](https://github.com/hakanberat/Scuba-Diving-Marketplace) — An ASP.NET Core MVC marketplace where divers find activities and request reservations, and dive centers manage their listings and bookings.
- [DiveHub Management Platform](https://github.com/hakanberat/DiveHub-Management-Platform) — A dive center management application built with an ASP.NET Core Web API, Blazor and SQL Server.
- [LifeDeck](https://github.com/hakanberat/LifeDeck) — A Blazor WebAssembly PWA that brings tasks, notes, a calendar and personal finance into one app.

**Technologies I work with:** C#, ASP.NET Core, Blazor, .NET MAUI, Entity Framework Core, Dapper, SQL Server and SQLite.
